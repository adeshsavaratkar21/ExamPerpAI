### 🚀 Featured Project: **[ExamPrepAi](https://github.com/adeshsavaratkar21/ExamPerpAI)**
> **Full-stack AI platform for university semester exam mastery and campus placement preparation.**
> 🌐 **Live Website:** [https://examperpai.vercel.app](https://examperpai.vercel.app)

- 📚 **Syllabus & PYQ Engine:** Custom PDF exam paper ingestion, AI question categorization, and in-app document viewing.
- 📝 **Handwritten Revision Sheets:** KaTeX formula rendering on ruled paper styling with single-AI note generation.
- ⚡ **Placement Mode:** 466-problem Striver A2Z DSA sheet with live LeetCode profile synchronization.
- 🖥️ **Core CS Visual Hub:** Interactive simulators for TCP 3-way handshakes, OSI/TCP layers, virtual memory layouts, and SQL joins.
- 🔐 **Zero Data Loss & Security:** Dynamic user session persistence across cold starts with live login history tracking.
